# Quickstart: 実行中のセッションの操作 (023)

**Date**: 2026-10-27 (`/cl-plan`) | **Spec**: [spec.md](./spec.md) (SC-009 / 「合否の扱い」)

実機の確認の手順。結果は `quickstart-results.md` に V-n ごとに書く。行えなかった V-n は「未実施」と書いてマージし、roadmap の X-6 の行に未確認の項目として残す (spec の「合否の扱い」)。

## V-0 準備

- 本番ビルド (`docs/discovery.md` の "Build / Test / Lint" 表のパッケージの行) を起動する
- WSL のランタイムと Win32 のランタイムのそれぞれに作業フォルダを 1 つずつ登録する
- モデルのカタログに 2 つ以上のモデルを持つ Provider を 1 つ用意する (effort を指定しないで起動する)

## V-1 権限モードの切り替え (WSL / Win32)

1. `default` で起動し、1 ターン話す (応答待ち)
2. 中央のヘッダの「権限モード」を `plan` にする。セッションが止まらず、ヘッダと概要のタブの権限モードが `plan` になることを確かめる
3. 「README に 1 行足して」と頼む。書き込みの tool が実行されない (計画だけが返る) ことを確かめる
4. `default` に戻し、同じ依頼で承認カードが出ることを確かめる
5. ターンの実行中に `plan` に切り替え、ターンが中断されないことを確かめる (spec US-1 AC3)
6. Claude Code が `status` / `init` で新しい権限モードを報告したかを、概要のタブの「現在の権限モード」で記録する (spec Assumptions の 2 つ目。報告が無くても表示は成り立つ)

## V-2 モデルの切り替え (WSL / Win32)

1. カタログの 1 つ目のモデルで起動し、1 ターン話す
2. ヘッダの「モデル」を 2 つ目にする
3. 次のターンの後、使用量のタブ (モデルごとのトークン) に 2 つ目のモデルが出ることを確かめる
4. 起動の effort が変わっていないこと (概要のタブ) を確かめる

## V-3 名前 (WSL / Win32)

1. 1 ターン話したセッションで「名前を変更」から「ログインの API 修正」と保存する。ヘッダと稼働中の行に名前が出ることを確かめる
2. 続けて 1 ターン話し、応答が今どおり流れることを確かめる
3. セッションを終了し、過去の区画に同じ名前の行が出て、検索で当たることを確かめる
4. その行を開いて過去ログが読めることと、X-9 の再開で続けられることを確かめる (transcript が壊れていない)
5. `claude` の CLI の `/resume` の一覧に同じ名前が出ることを確かめる (Claude Code の正本に記録された)

## V-4 押せない形

操作の種類ごとに確かめる (data-model §8.2 の表。spec US-1 AC3 / AC5・US-2 AC6・US-3 AC3)。

1. 終わった行・失敗した行・起動の後で最初の応答の前 (`launching`) — 3 つ (権限モード・モデル・名前を変更) とも理由つきで押せない
2. ターンの実行中・承認待ち — 「名前を変更」だけが「応答の実行中は名前を変更できません」で押せない。権限モードとモデルは押せる (V-1 の 5 と同じ)
3. 応答待ちで会話の id がある — 3 つとも押せる
4. 変更の結果を待っている間 — 3 つとも「変更中です」で押せない
5. Provider が既定 (null) で起動したセッション — 「モデル」だけが「この Provider にはモデルの一覧がありません」で押せない (U-10)

## V-5 改名と追記の重なり (research R-13)

- 応答が終わった直後 (1 秒以内) に名前を保存する、を 5 回繰り返す。毎回 V-3 の 3〜4 が通ることを確かめる。WSL (UNC 越しの追記) で特に見る。壊れたら利用者に返す (plan RK-03)
- 名前を保存した直後 (「変更中です」の間) にプロンプトを送る、を 3 回繰り返す。ターンが改名の結果の後に始まり (main の log の `[session] prompts held` / `released`)、プロンプトが失われず、V-3 の 3〜4 が通ることを確かめる (spec U-9)

## V-6 失敗の表示

- WSL のセッションで名前を保存する前にそのディストロを `wsl --terminate` で止め、「名前を変更できませんでした」が 1 行で出て、名前が元のままであることを確かめる (セッションは `claude` の終わりで失敗の行になる。表示の順は記録だけ)
