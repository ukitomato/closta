## 実装の進め方

- 本 feature は 1 つの PR で出す。Constitution の差分 (SH-010) と値の集合の変更 (BE-001〜BE-004) を分けずに同じ PR に含める (Constitution を正とするので、値の集合を改定より先に main に入れない。plan RK-01)。PR は改定手順 2 のため人間のレビューを待ち、レビューで AD-066 を accepted にする (spec FR-010)。AD-066 が accepted になるまでマージしない (夜間の規則でも。SH-012 で確かめる)。覆ったときは design-gate の結果を捨て、`/cl-design --from plan` から回し直す
- 節ごとに止めて、節の Independent Test が緑であることを確かめてから次へ進む
- 最初の区切り (MVP) は 先行 + 土台 + US-1 の BE (main が許可の 4 値と印を扱える。画面の振る舞いはまだ変わらない)。次に US-1 の FE (起動の設定 → composer の左の群 → 帯 → 再開の初期値) と E2E、Polish の順に積む。実機の V-1〜V-4 は US-1 の FE の後に確かめられ、V-5 は `isAutoModeAllowed` が true のランタイムがあるときだけ
